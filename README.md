# Elfsight Test Task (Rick and Morty API)

## На обсуждение
- Убрать `axios`: в текущем приложении он не даёт преимуществ по сравнению с `fetch`.
- Рассмотреть TanStack Query вместо самописной логики загрузки, кеша и обработки ошибок.
- Внедрить TypeScript для типизации данных API и пропсов.
- Заменить CRA на Vite для более быстрого и современного дев‑сервера.
- В требованиях указано «без сторонних UI‑библиотек», но в проекте есть `react-select` — нужно прояснить правило.
- API не предоставляет отдельные эндпоинты для вариантов фильтров (`status`, `gender`, `species`), поэтому значения взяты из документации и захардкожены.
- Можно добавить хук `useAppearanceDelay`, чтобы loader не мигал при очень быстрой загрузке.
- Нейминг обработчиков и компонентов неочевиден — нужен командный style guide.
- Требование «Не отображается Gender иконка возле имени персонажа» — фактически иконка уже отображается.
- Правило `react/jsx-no-bind` заглушено: в текущем размере проекта прирост производительности минимален, а код с тотальной мемоизацией становится менее читаемым. Имеет смысл договориться о более мягкой настройке линтера.

Учитывая, что предполагается внедрение решения в существующую кодовую базу, изменения были сознательно минимальными и опирались на текущую архитектуру и действующие конвенции проекта.
